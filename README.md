# ig_coarousal

This repository is the source of truth for the @whenkevintalks carousel routine.

## Required files

- `whenkevintalks_carousel_design_mastermind.md`: the design and editorial rules Claude must read first
- `carousel_topic_bank.md`: eligible ideas and used-topic history
- `published_log.csv`: every draft and published carousel
- `performance_notes.md`: post-performance learnings
- `research_notes/`: source material, links, filings, and verified notes
- `drafts/`: routine-generated Markdown drafts

## First setup

1. Upload this folder's contents to the root of the GitHub repository.
2. Commit the files to the `main` branch. An empty repository is invisible to the routine.
3. Connect this repository to the Claude Cloud Routine.
4. Keep the routine in draft-only mode until the Canva template and brand kit are connected.

## Important

The routine should generate carousel copy, design handoff and research notes first. It must not automatically publish finance content.
